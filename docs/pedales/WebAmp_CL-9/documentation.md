# WebAmp CL-9

**Version :** 1.0  
**Date :** 29 octobre 2026  
**Catalogue id :** `webamp-cl9`  
**Skin UI :** `ultra`  
**Type :** `chorus`

## 1. Présentation

Compresseur / limiteur de la gamme house : ATTACK TIME et SUSTAIN sur la rangée haute, LEVEL recentré dessous, MIN/MAX sous chaque knob.

Habillage (photo constructeur) : boîtier rouge vif, bloc de commandes noir, trois gros knobs, LED orange.

Référence matérielle d’inspiration : **Behringer CL9** (ligne compacte Ultra). Marque UI : **WebAmp** — pas un clone logo Behringer.

## 2. Paramètres UI

- **rate**
- **depth**
- **level**

## 3. Objectifs DSP (cibles)

1. Comportement cohérent avec une pédale compacte de la même famille d’effet.
2. Courbes de gain / mix / temps plausibles pour démo et calibration future.
3. Bypass soft sans click excessif.
