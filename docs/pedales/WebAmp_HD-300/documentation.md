# WebAmp HD-300

**Version :** 1.0  
**Date :** 29 octobre 2026  
**Catalogue id :** `webamp-hd300`  
**Skin UI :** `ultra`  
**Type :** `distortion`

## 1. Présentation

Heavy distortion + gain boost : LEVEL, TONE, DIST et GAIN BOOST alignés, BOTTOM (LO…HI) sous TONE, boîtier rose vif, LED orange.

Référence matérielle d’inspiration : **Behringer HD300** (ligne compacte Ultra). Marque UI : **WebAmp** — pas un clone logo Behringer.

## 2. Paramètres UI

- **boost**
- **distortion**
- **tone**
- **bottom**
- **level**

## 3. Objectifs DSP (cibles)

1. Comportement cohérent avec une pédale compacte de la même famille d’effet.
2. Courbes de gain / mix / temps plausibles pour démo et calibration future.
3. Bypass soft sans click excessif.
