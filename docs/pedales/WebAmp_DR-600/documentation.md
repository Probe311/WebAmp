# WebAmp DR-600

**Version :** 1.0  
**Date :** 29 octobre 2026  
**Catalogue id :** `webamp-dr600`  
**Skin UI :** `ultra`  
**Type :** `reverb`

## 1. Présentation

Digital reverb : LEVEL, TONE et TIME alignés, sélecteur MODE horizontal sous les knobs (ROOM/HALL/PLATE).

Habillage (photo constructeur) : boîtier argent satiné, bloc de commandes noir, LED ambre.

Référence matérielle d’inspiration : **Behringer DR600** (ligne compacte Ultra). Marque UI : **WebAmp** — pas un clone logo Behringer.

## 2. Paramètres UI

- **mix**
- **decay**
- **tone**
- **mode**

## 3. Objectifs DSP (cibles)

1. Comportement cohérent avec une pédale compacte de la même famille d’effet.
2. Courbes de gain / mix / temps plausibles pour démo et calibration future.
3. Bypass soft sans click excessif.
