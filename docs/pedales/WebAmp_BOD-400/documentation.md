# WebAmp BOD-400

**Version :** 1.0  
**Date :** 29 octobre 2026  
**Catalogue id :** `webamp-bod400`  
**Skin UI :** `ultra`  
**Type :** `overdrive`

## 1. Présentation

Bass overdrive + blend : LEVEL, HIGH, GAIN et BAL (DRY/OD) sur la rangée haute, LOW (CUT/+BOOST) recentré en dessous, MIN/MAX sous chaque knob.

Habillage (photo constructeur) : boîtier violet, bloc de commandes noir, cinq knobs sur deux rangées, LED orange.

Référence matérielle d’inspiration : **Behringer BOD400** (ligne compacte Ultra). Marque UI : **WebAmp** — pas un clone logo Behringer.

## 2. Paramètres UI

- **level**
- **gain**
- **bass**
- **treble**
- **blend**

## 3. Objectifs DSP (cibles)

1. Comportement cohérent avec une pédale compacte de la même famille d’effet.
2. Courbes de gain / mix / temps plausibles pour démo et calibration future.
3. Bypass soft sans click excessif.
