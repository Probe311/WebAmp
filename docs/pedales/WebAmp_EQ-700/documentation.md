# WebAmp EQ-700

**Version :** 1.0  
**Date :** 29 octobre 2026  
**Catalogue id :** `webamp-eq700`  
**Skin UI :** `eq`  
**Type :** `eq`

## 1. Présentation

EQ graphique 7 bandes : sept faders verticaux (100, 200, 400, 800, 1k6, 3k2, 6k4) répartis sur toute la façade, échelle ±15 dB, LED rouge.

Façade dorée : bloc de commandes dans la couleur du boîtier (pas de bloc noir), faders sombres et aucun potentiomètre.

Référence matérielle d’inspiration : **Behringer EQ700** (ligne compacte Ultra). Marque UI : **WebAmp** — pas un clone logo Behringer.

## 2. Paramètres UI

- **b100**
- **b200**
- **b400**
- **b800**
- **b1k6**
- **b3k2**
- **b6k4**

## 3. Objectifs DSP (cibles)

1. Comportement cohérent avec une pédale compacte de la même famille d’effet.
2. Courbes de gain / mix / temps plausibles pour démo et calibration future.
3. Bypass soft sans click excessif.
